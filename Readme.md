# IT Skills Tracker 💻

Application web de collecte et d'analyse des compétences en informatique.

## Fonctionnalités

- ✅ Formulaire de collecte de données
- ✅ Validation robuste des entrées
- ✅ Stockage dans base de données SQLite
- ✅ Analyse descriptive automatique
- ✅ Visualisations interactives (Plotly)
- ✅ Export des données en CSV
- ✅ Interface responsive

## Technologies

- Python 3.8+
- Streamlit
- Pandas
- Plotly
- SQLite

## Installation locale

```bash
pip install -r requirements.txt
streamlit run app.py
